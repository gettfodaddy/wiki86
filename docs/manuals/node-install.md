# Установка Remnawave Node



**Раздел:** remnawave  

**Адрес:** /manual/remnawave/node-install



Добавьте ноду в панели, запустите выданный Compose-файл и проверьте защищённое соединение с Panel.



## Твои данные

Заполни поля в форме на сайте: их значения подставляются в примеры по всей инструкции. Примеры ниже показывают поля и подсказки.

| Переменная | Поле | Пример | Подсказка |
| --- | --- | --- | --- |
| NODE_DIR | Каталог Node | /opt/remnanode | Каталог, в котором лежит docker-compose.yml ноды. |

Remnawave Node — отдельный контейнер с Xray-core. Панель не включает Xray-core, поэтому для полноценной работы нужна как минимум одна нода. Рекомендуется устанавливать её на отдельный сервер.

## Что понадобится

• Уже установленная и доступная Remnawave Panel.

• Отдельный сервер Ubuntu/Debian с SSH и правами `sudo`.

• Docker Engine с Docker Compose plugin.

• Сетевой доступ от сервера панели к ноде на заданном `Node Port`.

## 1. Установить Docker на сервер ноды

Подключись по SSH к **серверу ноды**, а не к серверу панели:

```bash
sudo curl -fsSL https://get.docker.com | sh
```

## 2. Создать ноду в панели

• Открой в панели **Nodes → Management** и нажми кнопку добавления ноды.

• Заполни форму: имя, адрес сервера ноды и остальные требуемые поля.

• Обрати внимание на `Node Port`: через него панель отправляет ноде внутренние API-запросы. Это не порт пользовательского подключения.

• Нажми **Copy docker-compose.yml**, чтобы скопировать сгенерированный конфиг.

Не придумывай compose-конфигурацию вручную и не меняй выданные панелью значения без необходимости.

## 3. Развернуть compose на ноде

На сервере ноды выполни:

```bash
sudo mkdir -p {{NODE_DIR}}
sudo chown "$USER":"$USER" {{NODE_DIR}}
cd {{NODE_DIR}}
nano docker-compose.yml
```

Вставь конфигурацию, скопированную из панели, и сохрани файл. Запусти контейнеры:

```bash
docker compose up -d
docker compose logs -f -t
```

Для выхода из просмотра логов нажми `Ctrl+C` — контейнер продолжит работать.

## 4. Завершить добавление в панели

Вернись к карточке создания ноды в панели:

• Нажми **Next**.

• Выбери нужный **Config Profile**.

• Нажми **Create**.

После подключения панель должна увидеть ноду. Проверь её состояние в списке Nodes.

## 5. Ограничить доступ к Node Port

В firewall сервера ноды разреши входящий `Node Port` только с IP-адреса панели. Для остальных адресов этот порт закрой. Клиентские порты и правила доступа задаются отдельно в настройках профиля и firewall.

## Проверка результата

• Контейнер ноды запущен: `docker compose ps`.

• В логах контейнера нет ошибок подключения.

• Нода отображается в панели в рабочем состоянии.

• `Node Port` доступен серверу панели, но закрыт от остальных источников.
